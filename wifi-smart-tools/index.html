📱 About WiFi Smart Tools

WiFi Smart Tools is a comprehensive network analysis and management toolkit designed for home users, network enthusiasts, and IT professionals who want to monitor and optimize their own WiFi networks.

✨ Key Features

🏠 Home Dashboard

  • Live SSID, IP address, gateway, and signal strength monitoring
  • Real-time network connection status
  • Quick access to all tools and features

🔍 WiFi Analyzer

  • Scan and discover nearby WiFi networks
  • View signal strength, channel, frequency band (2.4GHz/5GHz)
  • Check security type (WPA3, WPA2, WEP, Open)
  • Sort networks by signal, name, or security

⚡ Speed Test

  • Measure download and upload speeds with accurate results
  • Test network ping and latency
  • View detailed test history with timestamps
  • Connection quality assessment (Excellent to Poor)

📡 Signal Meter

  • Real-time WiFi signal strength monitoring
  • Visual signal quality indicators
  • Router placement optimization suggestions
  • Live dBm readings with color-coded strength

📱 Device Scanner

  • Discover all devices connected to your network
  • View device IP addresses, MAC addresses, and hostnames
  • Identify device types and manufacturers

🔒 Show Password

  • View saved WiFi passwords (requires system permissions)
  • Two-hour unlock timer with countdown
  • One network unlock at a time (mutual exclusivity)

  • Monitor real-time network performance metrics
  • Track signal strength changes over time
  • Connection stability monitoring

🔧 Router Settings

  • Quick access to router admin panel
  • Common router IP addresses (192.168.1.1, 192.168.0.1, etc.)
  • Direct navigation to router configuration

🔐 Password Generator

  • Generate strong, secure WiFi passwords
  • Customizable length and character types
  • Copy to clipboard functionality

📲 QR Share

  • Generate WiFi QR codes for easy network sharing
  • On-device generation (no data sent to servers)
  • Save and share QR codes

🛡️ Security Check

  • 7 comprehensive security tips for network protection
  • WPA3/WPA2 encryption guidance
  • Strong password recommendations
  • WPS security warnings
  • Router firmware update reminders

📝 Privacy Policy

WiFi Smart Tools ("the App") is developed to help users analyze and manage information about their own WiFi and network connections. This Privacy Policy explains how information may be handled when you use the App.

By using the App, you acknowledge that you have read this Privacy Policy.

1. Information We Collect

WiFi Smart Tools is designed to provide network-related tools without requiring users to create an account or provide personal information directly to us.

Depending on the features you use and the Android permissions granted to the App, the App may access certain device and network information required to provide its functionality.

Network Information

The App may access information related to your current network connection, such as:

  • WiFi connection information
  • Network name (SSID), where permitted by Android
  • Network status and connection type
  • IP address or network address information
  • Network speed and connectivity information
  • Connected device information (when using Device Scanner)

Network diagnostic data generated by the app's core features is processed locally on your device and is not sent to the developer's own servers. However, third-party services such as Google AdMob and Firebase may process certain information as described in their respective sections below.

2. Location and Nearby Device Permissions

Android may require location-related permissions for certain WiFi scanning and network discovery functionality. This is an Android system requirement, not our choice.

Important: The App does not intentionally use your location to track your physical movements. Location-related permissions are required by Android to allow WiFi scanning and related functionality. The app itself does not collect, store, or transmit your location data to the developer's servers.

You can manage or revoke permissions at any time through your Android device settings. Some features may not work correctly if the required permissions are denied.

3. Third-Party Services

The App uses the following third-party services:

  • Google AdMob: We use Google AdMob to display banner, native, interstitial, rewarded, and app open advertisements. Depending on applicable settings and consent, Google and its advertising partners may process information such as advertising ID, device information, IP address, approximate location, and ad interaction information for advertising, measurement, fraud prevention, and related purposes.
  • Firebase Services: We use Firebase Remote Config to manage app configuration and advertising-related settings, and Firebase Cloud Messaging (FCM) to provide push notifications. Depending on the Firebase services used, Firebase may process device identifiers, app configuration information, notification tokens, and related technical information.
  • Google Play Services: Core Android functionality

Note: Network diagnostic data generated by the app's core features is processed locally on your device and is not sent to the developer's servers.

For more information:

Google Privacy Policy

4. Network Speed Testing

The App provides network speed testing features such as ping, download speed, and upload speed tests.

These tests communicate with publicly available internet endpoints or servers to measure network performance. Test results are stored locally on your device and are not sent to our servers.

5. Data Storage

WiFi Smart Tools does not require an online account or cloud account for its core functionality. All data is stored locally on your device using:

  • Shared Preferences (for app settings)
  • SQLite database (for speed test history)
  • Local cache (for temporary data)

Information remains on your device unless you choose to share it using your device's sharing features (such as sharing QR codes).

6. Data Security

We take reasonable measures to protect information handled by the App:

  • Network diagnostic information generated by the App's core features is generally processed locally on your device. Certain features, such as speed testing, communicate with third-party internet endpoints as described in this Privacy Policy.
  • No account creation or cloud storage required
  • Industry-standard encryption for data transmission (HTTPS)
  • Regular security updates and bug fixes

However, no method of electronic storage or transmission over the internet can be guaranteed to be completely secure. You should use the App responsibly and keep your Android operating system updated.

7. Children's Privacy

WiFi Smart Tools is not specifically designed for children under 13 years of age.

We do not knowingly collect personal information from children. The App does not require account registration, which minimizes data collection.

If you believe that a child has provided personal information through the App, please contact us at support@toolsathi.com so that appropriate action can be taken.

8. Your Choices

You have the following choices regarding the App:

  • Permissions: Control app permissions through Android settings
  • Notifications: Manage notification preferences in app settings
  • Ad Settings: Manage through Google Ad Settings or device Privacy Options
  • Data Deletion: Uninstall the app to remove all locally stored data

If you disable required permissions, some features may not function as intended.
